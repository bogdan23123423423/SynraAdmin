Обновление данных

Раз в час бесплатный GitHub Actions копирует пользователей из Firebase Authentication в Firestore, а панель читает уже готовые данные. Сервер и тариф Blaze не нужны. Основной сайт Synra и его коллекции не затрагиваются.

  • 1Откройте на GitHub репозиторий с синхронизацией, вкладку Actions.
  • 2Выберите Synra Admin sync и нажмите Run workflow: обновление запустится сразу, не дожидаясь часа.
  • 3Через минуту нажмите кнопку обновления в этой карточке: состояние изменится.

Как считаются заходы

Заход — это последняя активность аккаунта по данным Firebase Authentication: вход в аккаунт или обновление сеанса, когда человек открывает Synra. Точность около часа. Человек, заходивший несколько раз за день, считается один раз.

Firebase не хранит историю заходов, поэтому дневная статистика копится только с первого обновления данных, а прошлые дни восстановить нельзя. Сообщения пользователей панель не учитывает и в Synra ничего не меняет.
