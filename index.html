Подключите Firebase

Вставьте конфигурацию веб-приложения вашего проекта Synra AI. Это публичные идентификаторы, а не секретные ключи. Найти их можно в Firebase Console: Project settings, раздел Your apps, веб-приложение, SDK setup and configuration.

Значения сохраняются только в этом браузере. Чтобы панель открывалась с любого устройства без этого шага, один раз впишите их в блок APP_CONFIG в начале скрипта файла index.html.

Пользователи из Firebase Authentication

Панель показывает пользователей из собственной коллекции-зеркала. Синхронизация читает всех пользователей Authentication через сервер и заполняет её. Существующие коллекции Synra она не трогает. Новые регистрации после этого попадают в зеркало автоматически.

Учёт сообщений

Последняя активность определяется по отправке сообщения в Synra, а не по входу в аккаунт. Панель не читает историю переписок: сервер увеличивает счётчик messageCount и обновляет lastMessageAt в момент отправки.

  • АСообщения уже пишутся в Firestore. Укажите их путь в CONFIG.messages.triggerPath в functions/index.js. Основной сайт менять не нужно.
  • БСообщения хранятся только на устройствах. Добавьте в Synra один вызов функции trackMessage после отправки сообщения пользователем (код ниже).

Структура базы данных

Сервер просматривает корневые коллекции, вложенные коллекции и поля нескольких документов. Значения полей и тексты сообщений не передаются, только названия и типы. По результату видно, где в вашем Firestore лежат пользователи и сообщения.
